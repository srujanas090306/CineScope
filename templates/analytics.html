Classification Findings

  • SMO achieved the highest accuracy at 55.21%.
  • Random Forest achieved the highest F-Measure (0.501) and Kappa statistic (0.1335).

  • No single classifier performed best across every evaluation metric.

PROJECT INSIGHTS

Overall Research Findings

The experiments demonstrate how different machine learning algorithms perform when analyzing movie-rating data. Classification models were evaluated using accuracy, precision, recall, F-measure and error metrics, while clustering models were evaluated using cluster agreement, distribution and execution time.

SMO achieved the highest classification accuracy, whereas Random Forest provided the strongest F-measure and Kappa results. In clustering, EM achieved higher cluster agreement, while SimpleKMeans offered faster execution.
