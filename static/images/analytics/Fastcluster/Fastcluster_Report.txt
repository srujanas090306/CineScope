
CINESCOPE - FASTCLUSTER HIERARCHICAL CLUSTERING REPORT

1. OBJECTIVE
To group movies based on genre, average rating, popularity,
and release year using hierarchical clustering.

2. DATASET
Dataset: MovieLens 100K
Total ratings: 100000
Unique movies: 1682
Features used: 21

3. PREPROCESSING
- Aggregated ratings at movie level.
- Extracted movie genres.
- Handled missing release years using median imputation.
- Applied log transformation to rating counts.
- Standardized numerical features using StandardScaler.

4. ALGORITHM
Algorithm: Hierarchical Agglomerative Clustering
Implementation: Fastcluster
Linkage: Ward
Distance: Euclidean
Optimal clusters tested: 2 to 8
Selected clusters: 2
